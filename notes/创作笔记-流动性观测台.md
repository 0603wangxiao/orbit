# 应用 · 流动性观测台（Liquidity Observatory）

## 它是什么

同一套框架在**资金面**上的展开：把美元与人民币的流动性、信用、日历、资产价格放进一套口径里看。

与另外三个应用的根本差别：**它是活的**——前三个是一次性建好的图谱与沙盘，这一套每天跟着数据走、也每天跟着时辰走。

自述定位：数据与结论分开呈现，供读者自行判断，不构成投资建议。

# 源头：《新月-时生》

## 打破常规的地方，就在第一句

**这是一个讲钱、讲流动性、讲数据的观测台。**

**它的起点是一首歌。**

**——一首跟理性无关、跟数据无关、跟金钱甚至相冲突的东西：**

```
艺术
```

**按常理，数据站该从网格、折线、仪表盘、冷色开始。这里却先有一首歌，才有这个站。**

**这不是「做完之后配了段背景音乐」。这是**构造顺序**：**

```
先有歌  →  才有封面  →  才有钟与影像
        →  才有插页  →  才有两篇《研判之外》
        →  才有那十一个视图的说法
```

> **一个用最不理性的东西，来给最理性的东西定调。**
> **这个站的反常，就是它想说的话。**

## 它本来是什么

配乐《新月-时生》——**它不是配乐，它是母题。**

**封面、时钟、两段影像、插页、两篇《研判之外》，全部从这首歌长出来。**

歌名两个词，就是全站的两个轴：

| 词 | 是什么 | 落在哪 |
|---|---|---|
| **新月** | **相位的起点**——不是满月，是还没亮起来的那一弯 | **右屏的影像** |
| **时生** | **时间是自己生出来的**——不是被计量，是正在发生 | **左屏的时钟** |

**——而且这不是比喻。**

**这首歌的歌手，名字就叫**时生**；歌名，就叫**新月**。**

```
时生（作者名） → 时生（时间在生） → 左屏那座钟
新月（歌名）   → 新月（相位的起点） → 右屏那段影像
```

> **一首歌的作者名与歌名，正好成了这个站的两根轴。**

# 核心命题：一体两面

**这个站真正讲的是：理性与感性、技术与艺术，是一件事的两个面，而且可以互相重构。**

不是「数据里加点诗意」，也不是「艺术外面包一层图表」。

而是：

> **同一件事，用技术的语言说得清，用艺术的语言也说得动。**
> **两种说法都成立，而且译得回去。**
> **译得回去，才算真懂——只通一面，是半懂。**

## 这里有两套逻辑，不能混用

**全站有两条轴。它们不是同一条，也不是一条的延伸。**

| | 轴一 | 轴二 |
|---|---|---|
| **是什么** | **技术 ↔ 艺术**<br>**理性 ↔ 感性** | **术语 ↔ 人话** |
| **解决什么** | **同一件事的两张脸** | **同一句话的两种说法** |
| **用在哪** | **封面（钟 / 影像）**<br>**研判之外（两篇）** | **详情页（每个指标）** |
| **能不能互换** | **互相重构——会改写对方的结论** | **只是翻译——说的是同一句话** |

**——轴一是**两种认识**，轴二是**两种表述**。**

**混起来就会出问题：把「人话」当成「艺术」，是把翻译抬高成了洞见；**
**把「艺术」当成「人话」，是把洞见降格成了白话。**

## 一体两面是结构，「合一」才是目的

**必须先分清这两件事，否则整套说法会站着不动。**

**一体两面不是成就，是事实。**

**理性与感性、技术与艺术，本来就长在同一件事上——承认这一点，只是把结构说清楚，不等于做到了什么。**

**真正的目的是**合一**。**

```
并置    左边是左边，右边是右边，各说各的          ← 结构成立，目的未达
合一    左边的话能被右边验证，右边的话能被左边修正   ← 目的达成
```

**——两面并排不难。难的是让它们互相校正之后，还能得出一个能动手的判断。**

**结构是给定的，合一是要争取的。**

**而且合一不是一次性完成的：每做一次判断，都要重新合一次。**

**——所以这个站的目录会把两面分开摆（结构），也会在同一个面板上让它们互相挑刺（目的）。**

# 一 · 封面：两种语言同时在场

**进去的第一眼不是数据，是一个时刻。**

左屏是**时生**，右屏是**新月**。

**——两屏并排，中间留一道窄缝。**


## 缝的意思

**理性与感性、技术与艺术，如果一上来就搅在一起，你分不清此刻是哪一面在说话。**

**所以必须先分开：**

```
左屏，只看时间     ← 只剩刻度、节律、可计量
右屏，只看世界     ← 只剩影像、意境、不可计量
```

**——分开，是为了让每一面单独站住，证明它自己就能说清一件事。**

**然后才允许它们合上。**

**进去以后，那十一个视图里，每一个数都同时带着两样东西：**
**它的口径（技术），和它此刻在说什么（感性）。**

> **缝，是「一体两面」里的那个「两面」。**
> **进去，才走上通往「合一」的那条路。**

**——没有缝，就没有两面；没有两面，那「合一」只是混沌成一团。**

**但进去也不等于合上了。进去只是开始——真正的合一，是每一次判断都要重新做一遍的事。**

## 左屏 · 时钟（时生）

**它不是一个显示时间的控件，它是「时间正在生出来」这件事本身。**

```
        18:07            ← 细体，不加重
    2026 / 11 / 05
  丙午年 戊戌月 癸未日 · 辰时
```

**四周环绕 60 根刻度，从 00 到 59，一圈就是一分钟。**

**秒在走，刻度在亮。**

**——这是这个站「技术的那一面」最纯粹的表达：**

- **可计量**：60 根，一根不多一根不少
- **可复现**：每秒都一样长
- **可对齐**：全球同一根秒针

**. 但它是用干支做注脚的。**

```
丙午年 戊戌月 癸未日 · 辰时
```

> **星期是日程的单位，干支是节律的单位。**
> **看流动性的人关心「到什么节气了、钱该紧还是该松」，不关心「今天周三」。**

**——技术给刻度，节律给意义。左屏同时有这两样东西，这就是「一体两面」第一次出现。**

## 右屏 · 影像（新月）

**两段影像，随日间 / 夜间切换。**

| 状态 | 画面 | 对应歌词 |
|---|---|---|
| **夜间（默认）** | **地球弧线，日出压在城市之上** | **「新月」的相位——光刚要出来，还没亮** |
| **日间（反色）** | **松堂、枯塘、初雪** | **「今夜初雪临枯塘」** |

**日间那一整套意象，就是歌的开头四句：**

```
今夜初雪临枯塘
古井落梅香
旧格窗  一人望
白花穿松堂
```

**——枯塘、落梅、格窗、松堂。**
**影像里那几块石、那几株松、那片薄雪，是这四句的样子。**

**——两段影像都不追求「科技感」，它们对应的是歌里的**意境**。**

**意境不是靠特效堆出来的，是靠一个具体的东西立住的。**

**中央三行导航（英文上、中文下）：**

```
RISK & SCENARIOS     风险与推演
OVERVIEW             总览
USD CIRCULATION      美元环流
```

**右下：进入观测台 →**

**封面只给三个去向。它是「选择往哪走」，不是「菜单」。**

# 二、那个 AI 解读机器人

## 为什么有它

**数据终端有个通病：给数，不给话。**

**四环 96、SOFR 3.97、HY OAS 3.40——写它的人知道这些数在说什么，第一次看的人不知道。**

**所以留了一个能问的地方。**

## 形态

**右下角一个橙色圆钮，点开是抽屉，不遮数据。**

**它会动：眼睛里有东西在转，偶尔眨一下。**

**——不是炫技。深色界面里，一个完全静止的控件容易被忽略；会动，才知道它在。**

## 分两层

```
规则引擎（默认）   离线、秒回、按模板解读常见指标，不用配置
接模型（可选）     填自己的 API Key，能理解任意问题、能调工具取历史/快讯/日历
```

**Key 只存在浏览器里，不经过本站服务器。**

**——第一层保证「谁都能用」，第二层决定「能用多深」。**

## 用途

**三件：把术语翻成人话；结合当前页面的数说话；站里没有的，给替代口径。**

## 局限

```
只能读站内已有的数据      编不出来，也不该编
不给预测                  给的是「什么算打脸」，不是「会怎样」
有的源就是没有            CDS 未接、FedWatch 概率缺、加密快讯无源
模型可能不听话            有时不调工具就作答，需要强制
规则引擎很笨              只会套模板，复杂问题答不了
```

**——这些不是「待修」，是当前事实。写着，是因为一个不肯说自己局限的解读工具，不值得信。**

## 为什么值得试

**这个站一直在问一件事：技术能不能不只是给数，还能给一句「这数在说什么」。**

**机器人是这个问题的试验品。**

**它可能答得不好、答错、或者只是套模板。**

**但这是第一次把「判断」也放进了工程里，而不只是把「数据」放进去。**

**——成了，这个站就不只是仪表盘；没成，那些数字还在，只是少了一句人话。**

# 三 · 研判之外：操盘（两篇插页）

**右上角 `OUTSIDE THE RESEARCH ↗`，点开是一整页杂志插页。**

**它不是弹窗、不是抽屉——它 `inset:0` **精确覆盖右半屏**，像把一张纸盖在屏幕上。**

**设计逻辑：**

```
站点夜间  →  插页是象牙纸白底   （暗室里的一张纸）
站点日间  →  插页是暗底         （亮处里的一块墨）
```

**衬线大字、大量留白、**无框无线无标记**。**

**——因为这一页里没有数据。它是判断之外的判断。**

## 两篇讲的是同一件事，只是语气不同

**两篇的内容是同一个：技术与艺术、理性与感性、一体两面、相互映照、相互重构。**

**不是「一篇讲技术、一篇讲艺术」。**

**——两篇都在讲这两样东西怎么互相照、怎么互相改。**

| | 正经版 | 非正经版 |
|---|---|---|
| **01** | 分节奏 | 分本质 |
| **02** | 分能力 | 分赌注 |
| **03** | 分用法 | 分禁忌 |
| **04** | **分刻度（身体与仓位）** | **分读数（身体比嘴诚实）** |
| **05** | **分凭据（叙事与痕迹）** | **分凭据（讲故事的都跑了，钱不会）** |

**——左边按顺序讲，右边直接掀底。**

**同一件事，一个坐在桌边说，一个凑近了说。**

## 为什么要讲两遍

**因为人分两种。**

**一种听得进道理，一种只听得进实话。**

**——道理讲给愿意听的人，实话讲给已经在里面的人。**

**两篇都在讲「技术与艺术是一体两面」，只是：**

```
正经版  把这句道理拆开讲清楚
非正经版 把这句道理按在你脸上
```

## 一体两面在文里怎么落地

**两篇走的是同一条路：先给刻度，再给质地，最后收到同一处。**

| | 正经版 | 非正经版 | 讲的是同一件事 |
|---|---|---|---|
| **01** | 分节奏 | 分本质 | **先认清这是什么局** |
| **02** | 分能力 | 分赌注 | **你拿什么在换** |
| **03** | 分用法 | 分禁忌 | **什么能做、什么不能** |
| **04** | **分刻度（身体与仓位）** | **分读数（身体比嘴诚实）** | **技术与感性在这里碰头** |
| **05** | **分凭据（叙事与痕迹）** | **分凭据（讲故事的都跑了，钱不会）** | **最后只看痕迹** |

**——第五节两篇用的是同一个词：凭据。**

**不是巧合：讲到最底下，技术面和感性面看的是同一样东西——**谁留下了痕迹**。**

## 相互映照

**技术回答「能不能」。**
**感性回答「该不该」。**

**——同一件事，两个问法都回答了，才算看清。**

## 相互重构

**这是更要紧的一层：不是并排，是互相改写。**

**① 技术会重构感性**

**你以为自己在「耐心等待」，一算仓位，其实在「不敢认错」。**
**——数字把那句自我叙事拆了。**

**② 感性会重构技术**

**所有指标都指向同一个方向，但你身体在抗拒。**
**——那种抗拒往往比指标早。**

**③ 两边都通，才算真看懂**

> **只通技术：会做，但不知道为什么做。**
> **只通感性：知道该不该，但下不去手。**
> **两边都通：手知道该放哪。**

# 四 · 详情页：术语与人话（轴二）

**进去以后，十一个视图都在做同一件事：**把「资本的三变六反」说清楚。

**用的是轴二：先按术语说一遍，再翻成人话说一遍。**

> **这里不涉及艺术。它只是把同一句话说给两种人听。**

## 技术面怎么读

| 层 | 看什么 | 语言 |
|---|---|---|
| **价格层** | SOFR、IORB、DR007、短端利率 | **利率是钱的租金** |
| **数量层** | 准备金、TGA、RRP、净流动性 | **余额是钱的存量** |
| **结构层** | 信用利差、期限结构、跨境利差 | **价差是钱的偏好** |

**三变在这里是三个深度：贵不贵 → 在谁手上 → 往哪去。**

## 另一套说法：把术语翻成大白话

**同样的三层，换成不端着的问法：**

| 层 | 问什么 | 说的是 |
|---|---|---|
| **价格层** | **钱现在多贵** | 借钱的成本 |
| **数量层** | **还剩多少能借** | 池子里有多少水 |
| **结构层** | **谁愿意借给谁** | 谁被信、谁被躲 |

**——这不是「艺术」，这是**人话**。**

**术语说给同行听，人话说给要动手的人听。**

**两套对不上，就是分歧点——那才是值得看的地方。**

## 六反在这里怎么用

**不设固定六项。**

> **问法固定为「本能想做什么 / 反过来该做什么」，条目数由当下位置决定，不硬凑六条。**

**——因为「反」不是一个清单，是一个**姿态**。位置一变，反的内容就变。**

# 五 · 落回操盘：最后只剩下手

**所有读数、所有语言、所有两面，最后都收敛到一个动作：**

```
做 / 不做 / 做多少
```

**《研判之外：操盘》两篇插页放在那里，是因为它们是**从读到做的桥**：**

- **技术面告诉你在哪儿**
- **人话那遍告诉你这是不是真的**
- **然后手自己决定要不要动**

> **仪表盘不会替你下单。它只能让你在动手之前，多知道一点。**

# 口径：三类内容，不可混淆

**与[[应用-地缘沙盘]]的数据护栏同源。**

| 类 | 定义 | 视觉 |
|---|---|---|
| **① 实算读数** | 直接来自 FRED / 财政部 / 中债 / 交易所接口，带 asof | 正常呈现 |
| **② 形态示例** | 暂无可接公开源的序列，按历史区间生成 | 图例标「模拟示例」，不参与判断 |
| **③ 推演** | 判断而非读数：情景、阈值、什么算打脸 | AI 段落中显式标出 |

> **查不到就写「无可靠数据」** —— 不估算、不写「约」「左右」。

**这套标注不只是洁癖，它是一道**认证机制**。**

**当复制品变得极廉价的年代，唯一稀缺的是「这确实来自某处」这个事实——**
**而三分类做的，就是把每一条信息「来自哪里、有多确定」写在明面上。**

# 设计

**深色为主，橙色（#FF5616）为唯一强调色。**

- **中美事件用色条区分：美国冷蓝、中国品牌橙**
- **「重要」快讯用一枚橙点标记，不做方框** —— 判断用点，分类用框
- **说明段落（「怎么读」）字号降至 11.5px，退到背景**
- **页脚四栏：这是什么 / 三类内容 / 数据口径 / 使用**
