# 流动性观测台 · 安装与交付

## 交付物

**只有一个文件：`流动性终端-安装包.zip`（122MB）**

解压后：

```
流动性终端-安装包/
├── 先看这个.txt
├── 流动性终端.app        ← 主程序，自带运行时与全部数据
├── 启动.command          ← 备用：出错时能看到原因
└── 停止.command
```

## 三步装好（macOS）

```
① 把「流动性终端.app」拖进「应用程序」
② 右键点它 → 选「打开」→ 再点「打开」
③ 完成。启动台里出现「流动性终端」
```

**第一次必须右键，之后正常双击。**

> 原因：App 未做代码签名。右键打开是 macOS 给未签名应用的唯一放行方式。

## 它自己带了什么

```

hero-dark.mp4       21MB
```

**装完不依赖任何外部安装。**

## 网络要求

**数据源在境外（FRED / 纽约联储 / 美国财政部）。**

**没有境外网络时：页面能打开，宏观数据显示「无可靠数据」。**

自检：

```bash
curl -s -o /dev/null -w "%{http_code}\n" --max-time 10 \
  https://fred.stlouisfed.org/graph/fredgraph.csv?id=EFFR
```

**`200` 正常 · `000` 连不上**

## 打不开时

| 现象 | 处理 |
|---|---|
| **双击无反应** | 右键 → 打开 |
| **提示「无法验证开发者」** | 右键 → 打开 → 再点「打开」 |
| **窗口是方形** | 关掉重开一次，Chrome 会记住尺寸 |
| **页面空白** | 等几秒（首次加载）；⌘⇧R 强刷 |
| **服务起不来** | 双击 `启动.command`，它会打印卡在哪一步 |

**彻底解除隔离：**

```bash
xattr -cr /Applications/流动性终端.app
```

## 停止服务

**App 只负责启动，不负责停止。**

**要彻底停：双击 `停止.command`（关端口 8899 / 8898）。**

**关掉窗口不会停，服务在后台继续跑，下次打开秒开。**

## 更新

**页面改动后，双击桌面「更新安装包.command」，会重新打包。**

**然后重新发给对方。**

> App 是快照，不会自动跟随更新。这是自包含打包的必然代价。
